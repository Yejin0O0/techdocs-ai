# 배포 — 기능 정의서

## 기능 개요

프론트엔드는 Vercel, 백엔드는 Railway에 배포하여 외부에서 접근 가능한 데모 환경을 구성한다.

## 요구사항

- 프론트엔드를 Vercel에 배포하고 공개 URL로 접근할 수 있다
- 백엔드를 Railway에 배포하고 API 요청을 받을 수 있다
- 환경변수가 각 플랫폼에 설정되어 있다
- 프론트엔드에서 Railway 백엔드 API를 정상 호출할 수 있다

## 비고

- 프론트엔드: GitHub 레포 연결 방식으로 Vercel 자동 배포
- 백엔드: Railway에 FastAPI 서버 배포
- ChromaDB는 로컬 파일 기반 유지 (재시작 시 데이터 초기화 허용)
