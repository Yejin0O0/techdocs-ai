# PRD — 데이터 시각화 컴포넌트

## 1. 개요

사이드바에 통계 탭을 추가하여 업로드된 문서의 현황(파일 수, 타입 분포, 상태)을 차트로 시각화한다.

---

## 2. 사용자 스토리

- **담당자(문서 관리자)**: 업로드된 문서의 현황(파일 수, 타입 분포, 상태)을 한눈에 파악하고 싶다

---

## 3. Out of Scope

- 채팅 히스토리 통계 (질문 수, 응답 시간) — 새로고침 시 리셋 문제로 제외
- 별도 `/stats` 페이지 — 사이드바 탭으로 충분

---

## 4. 용어 정의

| 용어  | 정의                                                    |
| ----- | ------------------------------------------------------- |
| top K | 질문당 검색 결과로 반환하는 상위 청크 수 (현재 TOP_K=5) |
