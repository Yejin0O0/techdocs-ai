# 데이터 시각화 컴포넌트 — Frontend Spec Fixed

## 기능 개요

사이드바에 통계 탭을 추가하여 문서 현황을 recharts로 시각화한다.

---

## UI 구조

### 사이드바 탭

- 기존 사이드바 상단에 `파일 목록 | 통계` 탭 추가
- 탭 상태는 사이드바 내부 `useState`로 관리 (page.tsx로 끌어올리지 않음)
- 파일 목록 탭: 기존 FileUploader + FileList 그대로
- 통계 탭: StatsPanel 컴포넌트

### StatsPanel 레이아웃

```
┌─────────────────────────┐
│  문서 현황               │
│  ┌──────────┐ ┌───────┐ │
│  │ 도넛차트  │ │바차트 │ │
│  │(타입별)  │ │(상태별│ │
│  └──────────┘ └───────┘ │
└─────────────────────────┘
```

---

## 차트 상세 스펙

### 1. 파일 타입별 도넛 차트

- 데이터: 기존 `documents` state (UploadedDocument[])에서 파일 확장자 추출
- 카테고리: PDF, MD, TXT, 기타
- **0개 카테고리는 숨김**
- 빈 상태(문서 0개): "업로드된 문서가 없어요" 텍스트 표시

### 2. 상태별 바 차트

- 데이터: `documents` state에서 status별 집계
- 카테고리: ready(준비 완료), indexing(인덱싱 중), uploading(업로드 중), error(오류)
- **0개 카테고리도 포함해서 표시** (전체 상태 현황 파악 목적)
- 빈 상태(문서 0개): 위 도넛 차트와 함께 빈 상태 UI
