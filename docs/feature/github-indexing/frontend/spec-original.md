# GitHub 인덱싱 — Frontend 기능 정의서

## 기능 개요

GitHub 공개 레포 URL을 입력하면 .md 파일을 크롤링해서 인덱싱하고, 기존 문서 목록과 함께 표시한다.

## 기능 요구사항

- GitHub 레포 URL을 입력하고 인덱싱을 시작할 수 있다
- 인덱싱 진행 상태를 실시간으로 확인할 수 있다
- 인덱싱된 레포를 문서 목록에서 확인할 수 있다
- 인덱싱된 레포를 삭제할 수 있다
- 채팅 응답의 코드 블록에 Syntax Highlighting이 적용된다

## 비고

- 공개 레포만 지원한다
- 크롤링 대상은 .md 파일 전체다
- 레포는 FileList에 파일과 함께 표시한다 (`owner/repo` 형태)
